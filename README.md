# NoAdKakaoMac V2

카카오톡 앱 파일과 서명을 수정하지 않고 광고 차단에 필요한 로그인 연결을 준비하는 macOS 메뉴 막대 앱입니다. 이 저장소는 배포·문제 신고용이며, 소스 코드는 비공개로 관리합니다.

**0.1.2 정식 릴리즈(빌드 9)를 준비합니다.** 로그인 연결 도우미는 최대 5분 동안 실행되며, 로그인 후에는 연결을 해제하거나 V2를 종료할 수 있습니다.

이번 버전은 Go 1.26.10의 표준라이브러리 보안 패치를 반영하고 배포 검사를 보완하는 유지보수 업데이트입니다. 사용 메뉴와 로그인 연결 흐름은 이전 버전과 같습니다.

## 다운로드와 호환성

[최신 릴리즈](https://github.com/abruption/NoAdKakaoMacV2/releases/latest)에서 **유니버설 DMG**와 `SHA256SUMS`를 받으세요. Apple Silicon과 Intel용 실행 파일이 함께 들어 있어 기종별로 고를 필요가 없습니다.

- 배포 파일: `NoAdKakaoMacV2-0.1.2-universal.dmg`
- 앱 버전·빌드: 0.1.2 / 9
- 이전 앱 코드의 기본 실행·자동 시험 확인: Apple Silicon(macOS 26), Intel(macOS 15)
- 0.1.2 산출물의 자동 검사 재검증은 아직 실행 전입니다. 이전 결과가 새 산출물의 검증을 대신하지 않습니다.
- 로그인·설치·복구 전체 시나리오와 모든 macOS 버전의 호환성은 검증 중입니다.

[0.1.2 변경 내역](CHANGELOG.md)을 참고하세요.

## 설치

1. 배포 출처와 `SHA256SUMS`의 체크섬을 확인합니다.
2. DMG를 열어 `NoAdKakaoMacV2.app`을 **응용 프로그램** 폴더로 옮깁니다.
3. 터미널에서 아래 명령을 직접 실행합니다.

```sh
xattr -dr com.apple.quarantine "/Applications/NoAdKakaoMacV2.app"
open "/Applications/NoAdKakaoMacV2.app"
```

Developer ID 서명·Apple 공증 없이 제공됩니다. 위 명령은 V2 앱의 격리 속성만 제거하며, 앱이 자동 실행하지 않습니다. 카카오톡 앱에는 적용하지 마세요.

## 사용 방법

1. App Store에서 설치한 카카오톡을 **응용 프로그램** 폴더에서 실행합니다.
2. V2 메뉴에서 **광고 차단 준비…**를 선택합니다.
3. **프록시 설치에 동의합니다**를 선택하고 **설치**를 누릅니다. macOS 승인 창이 나오면 내용을 확인해 주세요.
4. **로그인 준비 완료**가 표시되면 카카오톡에 로그인합니다. 이미 로그인했다면 직접 로그아웃한 뒤 다시 로그인해 주세요.
5. 로그인 후에는 **연결 해제**를 누르거나 V2를 **종료**해도 됩니다.

카카오톡을 자동 종료하거나 다시 실행하지 않습니다. 앱 메뉴의 **사용 방법…**에서도 순서를 확인할 수 있습니다.

## 연결 복구와 앱 삭제

**연결 복구 필요**가 표시되거나 카카오톡 연결이 어려우면 V2의 **연결 복구**를 눌러 주세요. 강제 종료·재부팅·승인 취소 등으로 연결 설정 정리가 남을 수 있습니다.

복구가 끝나기 전에는 앱이나 복구 기록을 삭제하지 마세요. 앱을 삭제할 때는 먼저 **연결 해제** 또는 **연결 복구**로 설정을 정리한 뒤 V2 앱을 휴지통으로 옮깁니다.
